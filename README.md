# 🔗 Singly Linked List in C

A menu-driven implementation of a **Singly Linked List** using the **C programming language**.

This project demonstrates how linked lists work using **structures, pointers, dynamic memory allocation, and functions**.

---

## 📌 Operations Included

### ➕ Insertion
- Insert a node at the beginning
- Insert a node at the end
- Insert a node before a specific node
- Insert a node after a specific node

### ❌ Deletion
- Delete a node from the beginning
- Delete a node from the end
- Delete a node before a specific node
- Delete a specific node
- Delete a node after a specific node

### 🔍 Other Operations
- Search for a node
- Count total number of nodes
- Replace data of a node
- Display the complete linked list

---

## 🧠 Concepts Used

- Structures
- Pointers
- Dynamic Memory Allocation
- `malloc()`
- `free()`
- Functions
- Singly Linked List
- Traversal of Linked List

---

## 💻 Example

A linked list containing:

```text
10 -> 20 -> 30 -> 40 -> NULL
```

Each node contains **data** and a pointer to the **next node**.

```c
struct node
{
    int data;
    struct node *next;
};
```
